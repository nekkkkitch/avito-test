# market

Простой рынок-сервис для хранения товаров и заказов локально и синхронизации с основным сервером.

## API

- `GET /ping` — проверка работоспособности
- `GET /products` — список товаров из локальной БД
- `POST /product` — сохранить или обновить товар и отправить его на основной сервер
- `DELETE /product` — удалить товар из локальной БД и уведомить основной сервер
- `POST /order` — сохранить заказ в локальной БД; одинаковые `id` запрещены

## Команды запуска

```bash
cd market
go run .
```

Сервис запускается на `:8081`.
